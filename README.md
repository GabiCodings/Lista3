# 📘 Lista de Exercícios 3 – Desenvolvimento Web Básico

Este repositório contém a resolução da Lista 3 de exercícios da disciplina de Desenvolvimento Web Básico, abordando temas como HTML semântico, listas, navegação, formulários, CSS, Grid, Flexbox e menu responsivo.

---

## 🛠️ Como visualizar os arquivos

### Pré-requisitos
Você só precisa de um navegador (como Chrome, Firefox ou Edge).

### Abrindo os arquivos
Basta dar **duplo clique** em qualquer um dos arquivos `.html` para abrir no navegador:

- `index.html` – Estrutura principal com tags semânticas e estilos via `styles.css`
- `listas.html` – Listas e navegação
- `feedback.html` – Formulário de feedback
- `galeria.html` – Galeria com Grid e Flexbox
- `menu.html` – Menu hamburguer responsivo

O arquivo `styles.css` está vinculado ao `index.html`
O arquivo `styles2.css` está vinculado ao `galeria.html`
O arquivo `styles3.css` está vinculado ao `menu.html`
